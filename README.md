## A bit about me

Most of my repositories begin with a small annoyance: a tool I wish existed, a coursework project that became more interesting than expected, or a device I wanted to understand properly.

I work mostly with TypeScript and Python. I also write C++, C#, PHP, and Kotlin when the project calls for them. Lately, that has meant web tools, Electron apps, Android kernels, and experiments around bootloaders and custom ROMs.

When I'm away from code, I'm usually adjusting a Linux desktop, sketching an interface in Figma, or making something in Blender. The line between engineering and visual work is blurry for me, and that's part of the fun.

## What I'm working on

- [OpenNOW-Modified](https://github.com/Chizuui/OpenNOW-Modified) is a TypeScript client for GeForce NOW.
- [WaEnhancer](https://github.com/Chizuui/WaEnhancer) is a set of Android tools for WhatsApp, written in Kotlin.
- [kaeru-gale](https://github.com/Chizuui/kaeru-gale) is a MediaTek bootloader payload for the Redmi 13C and POCO C65. It targets the `gale` device and `MT6768` platform.
